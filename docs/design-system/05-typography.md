# 文字とコンテンツ

このガイドは、文字の役割、読みやすさ、可変コンテンツへの耐性を揃えます。フォントの好みを一つに固定するのではなく、ユーザーがUIと会話の文字を個別に調整できる既存機能を保ちながら、サイズ・行間・階層の判断を統一します。

## 文字の階層

| 役割 | 基準 | 用途 |
| --- | --- | --- |
| 補助 | `text-xs` | 時刻、短い補助メタデータ。長文や必須情報には使わない |
| 小本文 | `text-sm` | 密度の高い一覧、補助的な説明、フォームラベル |
| 本文 | `text-base` | 通常の説明、入力、読み進める文章 |
| 強調本文 | `text-lg` | 小さな領域の導入、カード内の短い要約 |
| ページ見出し | `text-2xl`〜`text-3xl` | ページの主題。子見出しより明確に強くする |
| 大見出し | `text-4xl`以上 | 専用の空状態や導入画面など、限られた場面 |

既存テーマではUI文字サイズを14px基準にし、`text-*` の比率をユーザーのUI文字サイズに連動させています。会話本文は別の文字サイズとフォントを持てます。これらの設定を無視する固定px指定を通常のUIに追加しません。コード、端末出力、パスなど、等幅表示そのものに意味がある範囲では固定の等幅フォントを使えます。

## 見出しと本文

- 見出しは内容の階層と一致させ、同じ画面内で同じレベルの見出しに同じ文字階層・太さを使います。
- ページ見出しは最も強くし、セクション、カード、補助情報の順に視覚的な強さを下げます。
- 18px未満の文字は通常400以上のウェイトにします。小さな文字を薄い色や細いウェイトだけで弱く見せません。
- 本文の行高は通常1.5〜1.6、見出しは1.2〜1.3、短い大見出しは1.1を目安にします。折り返して3行以上になる文章には1.4以上の行高を保ちます。
- 長文はおおむね1行60〜75字程度を読み幅の目安にします。ただし会話、コード、diff、表など、横方向の作業領域が必要な内容は適切な表示幅を確保します。
- 見出しは必要な場合だけ軽い負の字間を使い、本文の字間は標準を保ちます。全大文字の短いラベルは文字間隔を少し広げて識別しやすくします。

## 可変テキストと構造化データ

- Project名、Thread名、ファイルパス、モデル名、エラー文、翻訳文の長さを決めつけません。レイアウトガイドに従い、折り返し、縮小、完全値への到達手段を役割に合わせて選びます。
- 重要な値を切り詰める場合は、コピー、詳細表示、アクセス可能な説明など、全文を確認できる方法を提供します。
- 更新される時刻、カウント、金額などは桁幅の変化で周囲が揺れないよう、必要な列に数字の等幅表示を使います。
- コードブロックとインラインコードはUI本文と区別し、長い行は横スクロールか折り返しのどちらが作業に適するか決めます。親ペインを押し広げないようにします。
- ユーザー入力や生成された長文は、短いカード用の行高・切り詰めルールをそのまま適用しません。

```tsx
<article className="max-w-prose text-base leading-relaxed">
  <h2 className="text-xl font-semibold leading-tight">Workspace instructions</h2>
  <p className="mt-2 text-base leading-relaxed">
    Long content can wrap without changing the surrounding page width.
  </p>
</article>
```

例は本文と見出しの役割を分けた形です。`max-w-prose` が適切でない会話やコード領域には適用しません。

## フォントと拡大

- UIと会話本文では現在のフォント設定経路を使い、無関係な画面で別のフォントファミリーを増やしません。
- フォールバックを含むフォントスタックで、日本語、英語、記号、コードが欠けずに表示されることを確認します。
- ユーザーの文字サイズ変更とUIズームを考慮し、固定高の行、ボタン、ダイアログで文字が切れないことを確認します。
- 文字サイズやズームの設定値を新たにコードへ複製しません。基準や範囲を変更する必要がある場合は設定仕様とこのガイドを同時に更新します。

## 現行コードとの対応

UIと会話のフォント・文字サイズ、UIズームは [`ui-preferences.ts`](../../src/app/ui-preferences.ts) で管理し、CSSスケールは [`index.css`](../../src/styles/index.css) にあります。既存の `text-*`、`font-*`、`leading-*` を使い、単発の数値を増やす前に同じ役割の画面を確認します。

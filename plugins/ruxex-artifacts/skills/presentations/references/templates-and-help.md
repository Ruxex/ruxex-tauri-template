# Local templates and API help

`presentation.help(query, options)` searches the local API index and built-in
examples. The bundled editable starter templates are `title-slide`, `two-up`,
and `agenda`; use `presentation.template(name)` to retrieve one and
`presentation.apply(template)` to add its starter slide.

The catalog is local and does not load remote or user-specific templates. For a
supplied deck, follow [template workflow](template-workflow.md) and inspect the
source before choosing a layout. A starter template is a starting point, not a
substitute for the user's branding or reference deck.

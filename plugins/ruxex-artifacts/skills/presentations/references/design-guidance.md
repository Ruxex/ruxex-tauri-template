# Slide design and review

Use this guidance when creating or changing slide layouts. Follow the user's
design direction and supplied template first.

## Match the content to the design

- Choose a small set of type sizes, weights, colors, and spacing values, then
  reuse them consistently across the deck.
- Give each slide one clear purpose. Use a subject title for context or process
  slides, and a takeaway title when the evidence supports a specific finding.
- Use the simplest layout that makes the relationship clear. Use tables for
  row-and-column evidence and charts for numeric comparisons. Keep labels next
  to the marks they explain.
- Keep related items aligned. Leave enough space around text and shapes. Check
  that lines do not cross labels and that images do not cover evidence.
- Prefer a few clear text groups over decorative kickers, footer fragments,
  repeated cards, or labels whose meaning is already obvious from the slide.
- Use one font family with clear heading and body styles. Choose a font that
  contains the required scripts. Check wrapping, padding, and bold text width.
- If a slide is crowded, edit the wording or rearrange the content before
  reducing the font size or removing required evidence.
- Use images that accurately represent the subject. Preserve the aspect ratio
  of logos, avoid cropping away evidence, and do not reuse an image unless it is
  a background or the user or template requires repetition.
- Use native diagrams when they make relationships easier to understand. Keep
  connectors clear of text and labels. Avoid programmatically drawing
  decorative illustrations; use image search or image generation for those
  assets. This restriction does not apply to user-requested editable diagrams,
  data charts, tables, or evidence that must remain editable.

## Review the deck

Review slide order and the balance of dense and simple slides. Inspect each
slide at a consistent readable size. Confirm the required content is present,
the main point is easy to find, text is readable, and objects fit without
unintended overlap.

For a supplied template, compare source and output side by side when the tools
can render both. Keep the original style when asked to preserve it. Ruxex's
PPTX importer retains supported images and crops, named layouts and
placeholders, simple inherited text/rectangle/line artwork, common cached chart
types, speaker notes, and basic rich-text styles. It does not recreate
inherited images or complex master artwork, arbitrary chart types, full rich
text range semantics, or PowerPoint-computed text layout. Its preview renders
only supported objects. Report where the local tools could not verify a
faithful match.

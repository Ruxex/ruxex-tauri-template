# Accessibility review

Keep text readable at presentation size and check every slide at full resolution.
Use meaningful alternative text for informative images. Give charts clear titles
and labels; do not rely on color alone to distinguish data. Use sufficient text
contrast and preserve logical reading order when using native objects.

Keep simple lists as structured paragraphs with native bullet settings instead
of separate text boxes or typed bullet characters. Check bullet indentation and
spacing in the exported presentation. Keep required table headings and data
labels visible.

The local model inspector does not calculate text overflow and the PPTX renderer
does not reproduce every screen reader or PowerPoint behavior. Treat these
checks as review aids, not a complete accessibility conformance audit.

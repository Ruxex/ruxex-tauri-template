# Chat status icons design

## Intent

左ペインのチャット一覧をコンパクトにし、ステータスの意味を文字ではなくアイコンで伝える。チャット名の位置がステータスによってずれないよう、ステータス領域のサイズを統一する。

## Scope

- `ChatListItem` のチャット名行の左にステータスアイコンを表示する。
- `running` はローディングスピナー、`completed` は緑の丸、`waiting` / `failed` / `stopped` も意味に対応したアイコンにする。
- ステータスがない場合はアイコン領域を表示しない。
- アイコン領域は同じ幅・高さの固定枠にし、チャット名の位置を安定させる。
- 左パディングを現状より少し増やす。
- 画面上のステータス文字は削除するが、各アイコンにはアクセシビリティ用の状態名を残す。

## Non-goals

- ステータスの判定ロジックや App Server のデータモデルは変更しない。
- チャット一覧以外のステータス表示は変更しない。

## Approaches

1. `ChatListItem` 内で状態ごとのアイコンを直接分岐する。変更量は小さいが、表示レイアウトと状態表示の責務が混ざる。
2. `ChatStatusIcon` を分離し、固定サイズの枠、状態別アイコン、アクセシビリティ名を担当させる。`ChatListItem` は一覧レイアウトに集中でき、状態ごとのテストもしやすい。この案を採用する。
3. 既存 badge の文字を CSS で隠す。固定サイズとアイコンの意味を保証しづらいため採用しない。

## Implementation notes

- Heroicons と既存の DaisyUI spinner を使い、依存関係は追加しない。
- `ChatStatusIcon` のアイコン枠は全状態で同一の `size-4 shrink-0` とする。
- `running` / `completed` / `waiting` / `failed` / `stopped` の表示と、ステータスなし時の非表示を UI テストで検証する。
- チャット名リンクのパディング変更と、従来の画面上の status text が出ないこともテストする。

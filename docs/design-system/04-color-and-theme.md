# 色とテーマ

このガイドは、色の値を全画面で固定するのではなく、色が担う意味を揃えます。Ruxexはライト／ダークのテーマプリセットと色のカスタマイズを持つため、部品は色名や画面位置ではなく、DaisyUIの意味的なテーマ色を通して色を選びます。

## 色の判断

- **色より役割を先に決めます。** 背景、本文、境界、主要操作、成功、警告、エラーのどれを表すかを定めてから、対応するテーマ色を使います。
- **色は状態の唯一の手掛かりにしません。** 状態色にはテキスト、形、アイコン、選択枠などを併用します。色の違いを識別できなくても意味と操作が伝わるようにします。
- **一つのビューで主要操作を一つに絞ります。** 同列の操作を複数の塗りつぶし色で競わせません。異なる意味を持つ状態やカテゴリの色はこの制限に含みません。
- **テーマ間で同じ意味を保ちます。** テーマを変えても、主要操作・成功・警告・エラーの役割を入れ替えません。
- **色を値の近さだけで流用しません。** 既存の意味的な色がなければ、別の見た目を借りず、必要な役割を先に仕様化します。

## 現在のテーマ色の役割

| DaisyUIの役割 | Ruxexでの用途 | 避ける使い方 |
| --- | --- | --- |
| `base-100` | 通常の面、カードや入力欄の表面 | 主要操作の強調 |
| `base-200` | 控えめな面、ホバー、選択中の補助背景 | 本文テキスト色 |
| `base-300` | 通常の境界や区切り | 小さな文字の色 |
| `base-content` | 主な本文、見出し | 成功・エラー状態の代用 |
| `primary` / `primary-content` | 主要操作とその上の文字、明確な選択強調 | 画面内の無関係な装飾すべて |
| `secondary` / `secondary-content` | 既存UIで第二の意味が必要なとき | `primary` と同じ意味の重複強調 |
| `accent` / `accent-content` | プリセットが提供するアクセント表現 | 成功や警告の意味の代用 |
| `neutral` / `neutral-content` | 中立的な塗り面とその上の文字 | 通常の本文や境界の使い分け |
| `info`, `success`, `warning`, `error` と各 `*-content` | 対応する状態表示、状態に関連する操作 | 状態と無関係な装飾 |

この表は既存のテーマ契約を説明するもので、各色ペアのコントラスト適合を保証するものではありません。色プリセットやユーザー設定値を変更・追加する実装段階では、実際に描画される文字と背景の組み合わせをライト／ダーク双方で測定します。

## コントラストと状態

- 通常サイズの文字は背景とのコントラスト比 **4.5:1以上**、大きな文字は **3:1以上**を確認します。大きな文字は24px以上、または太字18.67px以上です。
- 操作境界、フォーカス状態、意味を持つ図形は、隣接色とのコントラスト比 **3:1以上**を確認します。
- 半透明色、重ねた面、画像、色の混合は、宣言値だけで判断せず、最終的に合成された表示色を測ります。
- 成功／警告／エラーは色だけで示さず、簡潔な状態名や意味のあるアイコンも表示します。
- フォーカス表示はホバー表示と兼用せず、キーボード操作で見える輪郭を維持します。無効化や選択状態でもフォーカス表示を消しません。

## テーマを追加・変更するとき

1. Ruxexの意味的な役割に対応する色を用意し、テーマごとに意味を変えません。
2. 各 `*-content` は対応する塗り面の上で測定します。文字色を白または黒に固定して使い回しません。
3. ライト／ダーク両方で、通常文字、大きな文字、操作境界、フォーカス、選択、無効状態を確認します。
4. カスタム色を許す場合は、ユーザー入力を前提とした検証・警告・既定値への復帰方法を用意してから提供します。
5. 見た目のプレビューだけでなく、状態色がテキストやアイコンと一緒に意味を伝えることを確認します。

```tsx
<span className="badge badge-success gap-1">
  <CheckIcon aria-hidden="true" className="size-3.5" />
  Connected
</span>
```

例は色と文字・図形を組み合わせる意図を示します。特定テーマでのコントラスト値を示すものではありません。

## 現行コードとの対応

テーマプリセット、カスタムカラーのキー、適用処理は [`ui-themes.ts`](../../src/app/ui-themes.ts)、テーマCSSは [`index.css`](../../src/styles/index.css) にあります。色を使う実装では、DaisyUIテーマ変数を第一候補にし、画面固有のhex／rgb／oklch値を直接埋め込まないでください。個別色を追加する場合は、このガイドで役割・対象テーマ・検証方法を先に定義します。

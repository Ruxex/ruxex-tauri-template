# Speaker notes and review comments

Add speaker notes to a slide with `slide.addNotes(string)`. Notes are stored in
the PPTX and can hold source citations or image credits that the audience does
not need to see on the slide.

The local model also supports review threads targeted at a slide, editable
element, text range, or text match. Threads can receive replies and reactions,
and can be resolved or reopened. This review data is stored in Ruxex model data;
it is not written to PowerPoint comment parts.

Use speaker notes for delivered citations. Do not imply local review comments
will appear as native PowerPoint comments after export.

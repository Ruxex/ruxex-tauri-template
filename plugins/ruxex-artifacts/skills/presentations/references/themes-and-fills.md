# Themes, colors, fills, and effects

Set a deck's default font and theme color scheme through `presentation.theme`.
Colors accept six-digit hex, theme names such as `accent1`, and the included
Tailwind color tokens. Text and chart series currently use solid colors; shape
and slide backgrounds accept richer fill configurations.

Supported shape and background fills include none, solid, pattern, linear and
path gradients, and image fills that reference an image on the same slide.
Opacity and lightness adjustments can be applied to supported theme and token
colors. Rectangles support border radius and outer-shadow values. Exported
PowerPoint appearance may differ from the local preview for complex fills and
preset shapes.

Keep the palette small and reuse semantic colors across the deck. Use contrast
that preserves readability and avoid using color alone to convey status.

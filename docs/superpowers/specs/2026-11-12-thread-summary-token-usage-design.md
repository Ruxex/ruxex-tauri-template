# Thread summary token usage

## Intent

右列のスレッドサマリパネルで、現在のスレッドのトークン使用量を確認できるようにする。ストリーミング中の `thread/tokenUsage/updated` 通知を利用し、追加ポーリングは行わない。

## Goals / non-goals

- 合計使用トークン、直近ターンの使用トークン、コンテキストウィンドウ上限を表示する。
- 通知受信時に表示を即時更新する。
- 使用量データがない場合は空状態を表示し、既存のサマリ内容を壊さない。
- 料金計算、モデル別集計、履歴グラフ、バックエンドAPIの追加は対象外。

## Constraints

- 既存の `ThreadSummaryPanel` と App Server イベント同期を再利用する。
- 生成コードは変更せず、既存の `ThreadTokenUsage` 型を利用する。
- 表示は現在のUI言語・スタイルに合わせた英語ラベルとする。

## Approaches

1. イベントストアに最新のスレッド別トークン使用量を保持し、パネルが購読する（採用）。ストリーミング更新に強く、既存のイベント駆動設計に合う。
2. パネルから定期的にAPIをポーリングする。実装は局所的だが通信量と更新遅延が増えるため採用しない。

## Implementation outline

- イベントリデューサ／ストアに `thread/tokenUsage/updated` を反映する状態を追加する。
- `useThreadActivity` 相当の購読経路から最新使用量を取得できるようにする。
- `ThreadSummaryPanel` にトークン使用量セクションと、数値フォーマット・上限表示を追加する。
- 既存テストに通知反映と表示内容のケースを追加する。

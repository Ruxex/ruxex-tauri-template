# Finance presentations

Use this guidance for financial reporting, planning, valuation, and investment
decisions. A presentation does not need this guidance only because it contains
numbers. Follow the user's terminology and supplied template.

- State the result, outlook, or decision and the evidence that supports it.
  Distinguish actuals, forecasts, assumptions, and recommendations. Do not
  describe a proposal as approved or a plan as completed.
- When a point depends on numbers, state the period, comparison, and amount.
  Explain a cause only when evidence supports it. A target alone does not show
  how it will be reached, and a factual result does not need a slogan.
- Name the result, constraint, risk, or action directly. Preserve precise
  technical terms and quotations; no universal banned-word list replaces
  judgment.
- Check currency, scale, percentages, multiples, units, and signs. Do not
  attach currency to counts, years, or ratios. Keep assumptions and uncertainty
  visible when they affect a decision.
- Recalculate totals and ratios, then compare repeated values across tables,
  charts, titles, body text, and notes. Explain material rounding.
- Keep subtitles and short annotations only when they add information. Remove
  process commentary, repeated headlines, and unsupported conclusions.
